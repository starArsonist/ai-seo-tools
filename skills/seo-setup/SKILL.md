# Подключение seo-tools

Ключи лежат вне плагина, в папке `~/.seo-tools/` (или в `$SEO_TOOLS_HOME`), либо в настройках плагина. Плагин их только читает.

## 1. Проверь, что работает

Выполни в терминале из папки плагина:

```bash
uv run --project "${CLAUDE_PLUGIN_ROOT}" seo-tools doctor
```

Команда проверяет три источника и пишет, что не так. `seo-tools paths` показывает, где сервер ищет ключи и куда пишет отчёты. Если `uv` не найден, пользователю нужно поставить его: https://docs.astral.sh/uv/getting-started/installation/

Чини только то, что упало, по разделам ниже. Значения ключей в чат не выводи и в команды не подставляй: пользователь вписывает их сам.

## 2. Google Search Console

Нужен JSON-ключ сервисного аккаунта Google Cloud с включённым Search Console API.
1. Google Cloud Console → IAM → Service Accounts → создать аккаунт → Keys → Add key → JSON.
2. APIs & Services → Library → включить «Google Search Console API».
3. Положить JSON в `~/.seo-tools/` (имя любое) или указать путь в опции плагина «JSON сервисного аккаунта Google».
4. В Search Console на каждом сайте: Настройки → Пользователи и разрешения → Добавить пользователя → email сервисного аккаунта (поле `client_email` в JSON), уровень «Полный» или «Ограниченный».

«Сайт не найден в GSC» почти всегда означает, что пропущен шаг 4.

## 3. Яндекс.Вебмастер

Нужен OAuth-токен с правом `webmaster:hostinfo` (и `webmaster:verify`, если хочется видеть все хосты).
1. https://oauth.yandex.ru/client/new → создать приложение, доступы «Яндекс.Вебмастер», Redirect URI: `https://oauth.yandex.ru/verification_code`.
2. Вписать `YANDEX_CLIENT_ID` и `YANDEX_CLIENT_SECRET` в `~/.seo-tools/.env`.
3. `uv run --project "${CLAUDE_PLUGIN_ROOT}" seo-tools yandex-token` → открыть ссылку → скопировать код → `... seo-tools yandex-token <код>`. Токен запишется в `.env`.

Токен живёт около года. Когда инструмент пишет «токен истёк», повтори шаг 3. После обновления токена нужна новая сессия Claude Code: MCP-сервер читает ключи при старте.

`HOST_NOT_LOADED` — не ошибка доступа: Яндекс ещё не собрал данные по недавно добавленному сайту.

## 4. Вордстат

Работает через Yandex Cloud Search API, нужен платёжный аккаунт в облаке.
1. https://console.yandex.cloud → каталог → Сервисные аккаунты → создать с ролью `search-api.webSearch.user`.
2. У аккаунта: Создать новый ключ → API-ключ. Сохранить значение.
3. `YANDEX_CLOUD_API_KEY` и `YANDEX_CLOUD_FOLDER_ID` (id каталога, начинается с `b1g`) записать в `.env` или в опции плагина.

## 5. Финальная проверка

Снова `seo-tools doctor`. Если всё `[ok]`, но в сессии инструменты не видны, перезапусти Claude Code или выполни `/mcp`, чтобы переподключить сервер `seo`.
