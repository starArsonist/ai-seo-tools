# Семантика

Цель: список запросов с реальной частотностью, разбитый на кластеры, где у каждого кластера есть одна целевая страница. Плюс понимание, где сайт уже виден и где проще всего вырасти.

## 1. Вводные

Узнай тему или 1-3 маркерных запроса, регион (по умолчанию вся Россия) и для какой страницы собираем: новая или существующая. Если пользователь дал URL, открой страницу через WebFetch, чтобы понять её тему.

## 2. Расширь ядро

1. `wordstat_top(phrase=<маркер>, num_phrases=200, regions=[...])` по каждому маркеру. Из `associations` выбери похожие темы и прогони их тоже, если они по делу.
2. Отсей мусор: другие интенты (бесплатно, своими руками, скачать, вакансии, если это не наша тема), чужие бренды, гео не нашего региона. Минус-слова фиксируй, они пригодятся для повторных запросов.
3. Для 20-40 главных фраз узнай точную частотность: `wordstat_top(phrase='"<фраза>"')`. Широкая частотность считает все хвосты и сильно завышает спрос на саму фразу. В итоговой таблице показывай обе цифры.

## 3. Сезонность и регионы

- `wordstat_dynamics(phrase=<маркер>, months=24)`: есть ли сезон и растёт ли тема год к году. Если сезон есть, скажи, когда выпускать страницу, чтобы она успела проиндексироваться до пика (минимум за 1-2 месяца).
- `wordstat_regions(phrase=<маркер>)`, если бизнес работает не по всей стране: где спрос выше среднего (affinity больше 100).

## 4. Что уже есть у сайта

- Google: `gsc_query(dimensions=["query","page"], query_regex=<корни темы>, days=90, save_csv=true)`.
- Яндекс: `ya_search_queries(days=90, save_csv=true)`, затем отфильтруй по теме.

Отметь для каждой фразы текущую позицию и страницу. Запросы на позициях 4-20 с заметными показами дают самый быстрый рост: страница уже релевантна, её нужно усилить, а не создавать новую.

## 5. Кластеры

Группируй по интенту, а не по совпадению слов: «купить диван» и «диван цена» — один кластер (коммерческий), «как выбрать диван» — другой (информационный). Один кластер — одна страница. Если по кластеру на сайте уже видны две страницы, это каннибализация: предложи пользователю skill `cannibalization-audit`.

## 6. Результат

Сохрани CSV с колонками: кластер, запрос, частотность широкая, частотность точная, интент, позиция Google, позиция Яндекс, страница сейчас, целевая страница. Пользователю покажи сводку:

```markdown
# Семантика: <тема>, <регион>, Вордстат на <дата>

## Спрос
Общий объём по теме, сезонность, регионы.

## Кластеры
| Кластер | Интент | Главный запрос (точн./шир.) | Фраз | Целевая страница | Статус |
Статус: есть и в топ-3 / есть, позиции 4-20 / есть, дальше 20 / нет страницы.

## С чего начать
3-5 действий: усилить страницы на позициях 4-20, создать страницы под крупные кластеры без страницы, убрать конфликты.
```

Частотность Вордстата показывает спрос в Яндексе за 30 дней. Спрос в Google обычно другой; если пользователь спросит, скажи прямо, что точных цифр по Google у плагина нет, и предложи ориентироваться на показы в GSC по уже видимым запросам.
