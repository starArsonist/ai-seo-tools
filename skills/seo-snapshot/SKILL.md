# Срез сайта

Цель: за один проход собрать состояние сайта в обоих поисковиках, сравнить с прошлым и показать, что изменилось. Отчёт сохраняется, чтобы следующий срез было с чем сравнивать.

## 1. Определи сайт

Если сайт не назван, вызови `gsc_sites` и `ya_hosts` и спроси, какой нужен. Сайт может быть подключён только к одному поисковику: тогда делай срез по тому, что есть, и отметь пробел в отчёте.

## 2. Google (если сайт есть в GSC)

Посчитай даты: текущий период 28 дней, заканчивающийся 3 дня назад, и такой же предыдущий период перед ним. Затем:

1. `gsc_query(dimensions=["date"], days=56)` — динамика по дням за оба периода. Сложи клики и показы по каждому периоду.
2. `gsc_query(dimensions=["query"], start_date, end_date, row_limit=1000, save_csv=true)` для текущего периода и то же для предыдущего. Сравни: какие запросы выросли и упали сильнее всего по кликам, какие появились, какие исчезли.
3. `gsc_query(dimensions=["page"], ...)` за оба периода — то же по страницам.
4. `gsc_sitemaps` — ошибки и дата последнего скачивания.

## 3. Яндекс (если сайт есть в Вебмастере)

1. `ya_summary` — ИКС, страницы в поиске и исключённые, активные проблемы диагностики.
2. `ya_search_queries(days=28, save_csv=true)` и за предыдущие 28 дней через `start_date`/`end_date`.
3. `ya_indexing_history(days=90)` — тренд числа страниц в поиске.
4. `ya_search_events` — что недавно выпало из поиска и по какой причине.
5. `ya_sitemaps`.

`HOST_NOT_LOADED` означает, что Яндекс ещё не собрал данные по сайту. Запиши это в отчёт и иди дальше.

## 4. Сравни с прошлым срезом

CSV из шагов выше сохраняются в `reports/<домен>/<дата>/` (точный путь есть в поле `saved_to`). Поищи через Glob файл `snapshot.md` в соседних папках с датами этого же домена. Если он есть, прочитай его и добавь в отчёт, что изменилось с той даты.

## 5. Отчёт

Сохрани `snapshot.md` в ту же папку, где лежат CSV этого среза, и покажи его пользователю. Структура:

```markdown
# <домен>: срез на <дата>

## Главное
2-4 пункта: что изменилось и почему это важно, с цифрами.

## Google, <период> к <предыдущий период>
| Метрика | Сейчас | Было | Изменение |
(клики, показы, CTR, средняя позиция)
Выросли: топ-5 запросов и страниц по приросту кликов.
Упали: топ-5 по потере кликов.

## Яндекс
ИКС, страниц в поиске / исключено, тренд за 90 дней.
Запросы: та же таблица и те же топы.
Выпавшие страницы и причины.

## Проблемы
Диагностика Вебмастера, ошибки sitemap, страницы, выпавшие из индекса.

## Что сделать
Нумерованный список по приоритету. У каждого пункта: где, что и на основании каких данных.
```

Не раздувай отчёт: если раздел пустой, напиши одну строку «изменений нет» или «данных пока нет». Средние позиции сравнивай осторожно: при росте показов по новым дальним запросам средняя позиция ухудшается, хотя сайт растёт. Если видишь такое, так и напиши.
